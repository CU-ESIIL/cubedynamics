# Verbs API

The complete, generated [verb and callable-helper index](../reference/verbs/index.md)
is the canonical reference. Each entry has Usage, Arguments, Accepts, Returns,
Order / grammar behavior, Minimal example, Works with, and See also.

For teaching, use [Learn: verbs](../learn/verbs.md).
For complete analyses, use [Vignettes](../vignettes/index.md).
Project-specific fire, synchrony and biological vocabulary remains distinct
from the small [core grammar](../concepts/core_and_projects.md).

Common operations: [mean](../reference/verbs/mean.md),
[variance](../reference/verbs/variance.md), [anomaly](../reference/verbs/anomaly.md),
[zscore](../reference/verbs/zscore.md), [plot](../reference/verbs/plot.md),
[overlap](../reference/verbs/overlap.md).

Specialized workflows: [spatial blocks](../recipes/spatial_synchrony_units.md),
[states and events](../vignettes/states_and_events.ipynb),
[Fire VASE](../capabilities/fire-vase.md).
