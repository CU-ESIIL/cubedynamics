# Source comparison documentation homes

The handwritten manuscript inventory has been consolidated into the generated
[noun library](../library/index.md) and [source directory](../library/sources/index.md).
These derive current signatures and catalog facts from runtime and reviewed
editorial contracts. Each page supplies units, resolution, coverage, native
variables, access/authentication, transformations and limitations.

Compare [temperature products](../library/nouns/temperature.md) without assuming
that Celsius/kelvin conversion or regridding establishes scientific equivalence.
[Temporal alignment](../concepts/temporal_alignment.md) explains differing support.

[Phase 1 QA](phase1_qa.md) owns production fixture checks and serving revisions;
[candidate readiness](source_projects/production.md) owns elevation, roads and
streamflow promotion status. Access tested, adapter structure checked, and
scientific equivalence validated are separate claims. No general source
equivalence evaluation is supplied.
